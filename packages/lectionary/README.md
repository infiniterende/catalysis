# @catalysis/lectionary

Which readings are read at Mass each day, from the Lectionary for Mass for the dioceses of the United
States, as citations: one JSON file per year, keyed by `MM-DD`.

Generated by `node scripts/import-lectionary.mjs` from
[acupofjose/catholic-readings-api](https://github.com/acupofjose/catholic-readings-api) (MIT), pinned to a
commit. The script checks that every citation can be read by `parsePassage` in `packages/api`.

**Citations only.** The app shows the text of each reading from its own Bible (`@catalysis/bible-nabre`), so
nothing is fetched from another site when someone reads. The USCCB's page for each day has the full
Lectionary text, including the psalm's refrain and the Gospel acclamation, which citations cannot give.

## Limits

- The source gives one set of readings per day. Days with more than one Mass (Christmas, the Easter Vigil,
  Palm Sunday's procession) and optional memorials' proper readings are not separated.
- Partial verses ("26b") are shown as whole verses.
- Coverage ends where the source does (see `LECTIONARY_RANGE`). Re-run the import, with a newer commit,
  to extend it.
