# @catalysis/catechism

The Catechism of the Catholic Church, in English, split into one JSON file per page of its table of
contents so the app loads only what is read.

Generated by `node scripts/import-catechism.mjs` from
[nossbigg/catechism-ccc-json](https://github.com/nossbigg/catechism-ccc-json) (release v0.0.2, checked by
SHA-256), itself a scrape of the text on vatican.va. Do not edit the files here by hand; change the script
and re-run it.

| File | Contents |
|---|---|
| `toc.json` | The table of contents in reading order: depth, label ("Part One", "Article 3"), title, the page that holds it, and the first and last paragraph numbers beneath it. |
| `pages/<id>.json` | One page: headings, numbered paragraphs (`n`), quotations (`q`), and footnotes. A run is a string, styled text (`i`, `b`), a footnote marker (`f`), or a Scripture reference (`s`: `{ b: USFM, c, v }`). |
| `search.json` | `[number, text]` for each of the 2,865 paragraphs. |

## Corrections made by the import

- **§2267** is replaced with the text approved by Pope Francis and published on 1 August 2018
  (Rescriptum "ex Audientia SS.mi"), with its footnote. The source predates the revision.
- Sentences the scrape left beginning in lower case are capitalised.
- Headings set in capitals are put in title case.
- Scripture references in footnotes, and the few inside the text, are linked to the Bible reader, using
  the book and chapter in the source's links to vatican.va. References to Canon Law are left as text.
