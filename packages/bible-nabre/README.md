# @catalysis/bible-nabre

The New American Bible, Revised Edition, one JSON file per book.

Generated by `node scripts/import-nabre.mjs` from
[nirmalben/bible-nabre-json-dataset](https://github.com/nirmalben/bible-nabre-json-dataset)
(pinned to commit `768abdb`). Do not edit the files in `books/` by hand; change the script and re-run it.

## Known limits of the source

The source was scraped a verse at a time, so:

- Poetry has lost its line breaks.
- Section headings were fused to verse text. The import script separates them (`h`, `m`), but a few
  remain inline, notably in Esther's Greek additions and the speaker labels in the Song of Songs.
- Footnotes and cross references are not included.
